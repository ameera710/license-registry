# License Registry

مشروع أولي لبناء سجل تراخيص باستخدام Hyperledger Fabric، مع API وواجهة ويب وخدمات IPFS والتحقق.

## بنية المشروع

- `network/`: إعداد الشبكة والمؤسسات وسكربتات التشغيل.
- `chaincode/`: عقد الترخيص ومخطط البيانات والاختبارات.
- `api/`: المسارات ووحدات التحكم والخدمات.
- `web/`: مصدر الواجهة الأمامية.
- `caliper/`: إعدادات اختبارات الأداء.
- `docs/`: وثائق المعمارية والبيانات والتحكم بالوصول والتجارب.
- `tests/`: اختبارات API والتكامل.

> هذا scaffold أولي فقط؛ لم تُضف بعد منطقًا وظيفيًا أو إعدادات أسرار/شبكة.
